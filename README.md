# Battle of the Storm

Top-Down-Battle-Royale mit Helden. Dieses Repository enthält die Design-Dokumente und den Prototyp in Unreal Engine 5.8.

| Inhalt | Ort |
| --- | --- |
| Game Design Document | `docs/GDD.md` |
| Technical Design Document | `docs/TDD.md` |
| Stand des Prototyps, Start, Steuerung, Entscheidungen | `docs/PROTOTYP.md` |
| Unreal-Projekt | `BattleOfTheStorm.uproject`, `Source/`, `Config/` |
| Spieldaten (Helden, Fähigkeiten, Sturm, Beute, Karte) | `Content/BotS/Data/GameData.json` |

## Schnellstart

1. Unreal Engine 5.8 und Visual Studio 2022 mit C++-Spieleentwicklung installieren.
2. `BattleOfTheStorm.uproject` öffnen und den Bau des Moduls bestätigen.
3. „Play“ drücken. Es starten ein dedizierter Server im Editor und zwei Clients. Freie Plätze füllen Test-Bots.

Alles Weitere steht in `docs/PROTOTYP.md`.
